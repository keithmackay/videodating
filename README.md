# videodating

## Description

A speed-dating video platform. Participants sign up, express preferences, and are billed via Stripe. At a designated event time, they are paired based on their preferences and dropped into a time-bounded video call. Calls support recording and automatic transcription. Post-event analysis of video transcripts (and potentially audio/facial expression signals) is used to gather compatibility-relevant information about participants. The platform includes an administration capability for running and managing events.
